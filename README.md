# signal-acquisition-brymen

signal-acquisition-brymen is a C# application that enables interactive serial communication (via RS232) with the RIGOL DM3051 digital multimeter.

## Key Features

- Communicate with your RIGOL DM3051 multimeter using a serial (RS232) connection.
- Read specific measurement parameters and monitor them over a user-defined time period.
- Display measurement values in real time, including interactive charts for easy analysis.
- Save your measurement results to a CSV file for later review or processing.
- Simple and intuitive user interface for easy operation.

## How to Get Started

1. Clone this repository.
2. Open the project in your preferred C# development environment (such as Visual Studio).
3. Build and run the application.
4. Connect your RIGOL DM3051 multimeter via an RS232 serial port and start communicating!

## Requirements

- .NET Framework (or .NET Core/5+/6+, specify as needed)
- RIGOL DM3051 digital multimeter
- RS232 serial connection
